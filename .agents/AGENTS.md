# SmartChoice プロジェクト運用ルール

## プロジェクト概要
AIが相場を分析し、見積もり・契約・価格交渉までサポートする「相場比較や価格交渉支援を目的としたウェブアプリ（およびそのLP）」。

## ディレクトリ構成（2つのリポジトリ）
SmartChoiceは以下の2つのディレクトリ・GitHubリポジトリで構成されている。作業時は必ず両方の整合性を確認し、`smart_choice\.agents\AGENTS.md` のアフィリエイトURL絶対保護ルールも併せて厳守すること。
- **Webアプリ本体**: `C:\Users\User\.gemini\antigravity-ide\scratch\smart_choice`（本番: `https://smart-choice.onrender.com/`）
- **紹介用LP**: `C:\Users\User\.gemini\antigravity-ide\scratch\smart_choice_lp`

## 基本方針
1. **最高峰のデザイン品質とユーザー体験**: ウェブアプリ・LPともに、訪れたユーザーに強い信頼感とインパクトを与える高品質なデザインを維持する。
2. **ノーコスト運用**: 余計なサーバーコストをかけず、無料ホスティング等で運用する。
3. **正確な情報の提供**: 事実に基づかない誇大表現や不正確な技術情報を記載しない（ハルシネーションの徹底排除）。
4. **影響範囲の厳密な確認**: コードを変更する際は、必ず実行前・デプロイ前に影響範囲・デザイン崩れがないか厳格に自己チェックすること。
5. **アフィリエイトリンクの絶対保護**: Webアプリ本体の `affiliate_config.json` および `index.html` 内のASPリンクは収益に直結する超重要データであり、いかなる改修時にも消失・上書きしてはならない。
